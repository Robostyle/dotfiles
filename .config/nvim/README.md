# Introduction

## Plugins

### [arrow.nvim](https://github.com/otavioschwanck/arrow.nvim)

A plugin made to bookmarks files (like harpoon) using a single UI (and single
keymap).

| Key | Description | Mode |
|-----|-------------|------|
| m   | Per buffer mappings | n |
| ;   | Leader key | n |

### [flash.nvim](https://github.com/folke/flash.nvim)

Lets you navigate your code with search labels, enhanced character motions, and
Treesitter integration.

| Key | Description | Mode |
|-----|-------------|------|
| <c-s> | Toggle Flash Search | c |
| <c-space> | Treesitter Incremental Selection | n, o, x |
| r | Remote Flash | o |
| R | Treesitter Search | o, x |
| s | Flash | n, o, x |
| S | Flash Treesitter | n, o, x |

### [oil.nvim](https://github.com/stevearc/oil.nvim)

| Key | Description | Mode |
|-----|-------------|------|
| <leader>o | Show file explorer | n |
